# Contributing

1. Fork the repository and create a feature branch.
2. Keep changes small and focused; code comments in English.
3. Test by converting `examples/Philips_PM5544.svg` and comparing the render with `examples/Philips_PM5544_render.png`.
4. Update `CHANGELOG.md` under `[Unreleased]` and open a pull request.

By contributing you agree that your contributions are licensed under GPL-3.0.
