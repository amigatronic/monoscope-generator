## [0.1.0] - 2026-09-28

### Added
- `svg_to_json.py`: SVG to Portable Vector IR v2 converter (CLI and tkinter dialogs).
- `svg_geometry_core.py`: transform, path, arc, CSS style, gradient and clip-path normalization.
- `json_to_pdf.py`: vector PDF exporter (ReportLab) with clipping, opacity and linear gradients.
- `render_reference.py`: Pillow reference renderer with adaptive curve flattening and supersampling.
- `monoscope_viewer.html`: browser viewer with pan, zoom, fit and 100% modes.
- Philips PM5544 sample (SVG, JSON, PNG render) with CC BY 2.5 attribution.
